# Two-minute demo script

## 0:00–0:20 — Problem

“Notion Student OS keeps every deadline in one place, but a deadline list still does not tell a student what to do tonight or whether the week is already overloaded. PulsePlan turns that stored information into a realistic action plan.”

## 0:20–0:50 — Smart briefing

Open **Overview**.

“PulsePlan reads assignments from Notion and scores each one using deadline urgency, effort left, priority, and momentum. The top recommendation explains itself, so the student can trust it.”

Point to the four metrics and weekly capacity chart.

## 0:50–1:25 — Adaptive plan

Open **Study plan**.

“The scheduler breaks work into focus blocks, protects breaks, limits one subject to two hours per day, and never puts a block after its deadline.”

Change capacity from `3h` to `2h`, then `4h`.

“The warning changes immediately when the work no longer fits. A student can act while there is still time.”

Select one session, then mention CSV export and Notion sync.

## 1:25–1:45 — Transparency

Open **Assignments**, then expand **Why this score?**

“This is not a black box. Every point comes from one of four visible signals.”

## 1:45–2:00 — Notion value

Open **Notion setup**.

“Notion remains the source of truth. PulsePlan reads the Student OS and writes a focused weekly plan back as Study Sessions. Demo mode lets anyone test the complete product safely.”
